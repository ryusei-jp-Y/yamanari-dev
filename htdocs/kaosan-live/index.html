線画イラスト1枚を、マイク音声に合わせて口が動き、瞬きし、少しだけ揺れる会議用アバターにするElectronアプリです。 OBS StudioのWindow CaptureとVirtual Camera経由でZoomへ渡します。

Direction

顔出しせずに、会議にいる感じを作る

顔認識やカメラキャプチャは使わず、1枚の画像とマイク音声だけで、口、瞬き、顔全体の微細な動きを作ります。 個人用・単一イラスト前提に絞り、マイモデル初期値や調整UIを会議で使いやすい形へ寄せています。

実装済み

  • Control WindowとOBSキャプチャ用Avatar Windowの2ウィンドウ構成
  • Web Audio APIでRMS、Peak、口開き、Talk、無音判定を解析・表示
  • Canvasで口消しパッチ、動的な口、瞬き、待機揺れを描画

技術スタック

  • Electron / Vite / TypeScript
  • HTML Canvas / Web Audio API
  • BroadcastChannel / Electron IPC / JSON settings
