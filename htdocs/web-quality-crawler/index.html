Use case

ローカルで常用し、必要な時だけ外へ見せる

品質改善を継続的に回すWeb制作・運用チーム向けのローカル常用ツールです。 ローカルのExpress dashboardを本番実行環境として起動し、必要に応じて Cloudflare Tunnel経由で公開します。

技術ハイライト

  • 1ターゲットごとの子プロセス分離でクロールの安定性を優先
  • Lighthouseと独自ルールを同じダッシュボードに統合
  • AI評価と修正提案をキャッシュしてコストと再実行時間を抑制

技術スタック

  • Node.js / Express / SQLite
  • Playwright / Lighthouse
  • Claude API
